# Proveedores de movilidad y delivery — ronda 1

- Uber Direct documenta cotización, creación de entregas, URL de rastreo y webhooks; requiere credenciales, sandbox y aprobación de producción. La disponibilidad API en Colombia debe confirmarse. [Uber Developers](https://developer.uber.com/docs/deliveries/get-started) — confianza alta.
- Uber Riders API documenta estimar, crear, consultar, modificar, cancelar y rastrear viajes; algunos endpoints requieren aprobación. No se confirmó acceso productivo para un tercero nuevo en Colombia. [Uber Developers](https://developer.uber.com/docs/riders/references/api) — confianza alta en capacidades, media en disponibilidad local.
- Rappi ofrece API autorizada de partner/POS para catálogo y órdenes del canal Rappi; no apareció evidencia pública de una API para despachar pedidos externos originados fuera de su marketplace. [Rappi Colombia](https://merchants.rappi.com/es-co/para-que-sirve-el-integrations-manager-de-rappi) — confianza alta.
- inDrive ofrece en Colombia un asistente propio de WhatsApp para servicios empresariales; no apareció API pública para que un orquestador externo cree y siga solicitudes. El portal legal público localizado no permitió verificar una cláusula específica sobre middleware. [inDrive](https://indrive.com/es-co/business) · [Portal legal](https://indrive.com/es-co/legal) — confianza alta para el asistente; media sobre ausencia pública.
- DiDi Food admite comercios colombianos e integración POS asociada, pero no apareció documentación oficial de API pública transaccional para terceros. [DiDi Food](https://web.didiglobal.com/co/food/restaurantes/) — confianza media.
- Taxia Life ofrece despacho empresarial, vales y app web; no apareció API pública para terceros. Está registrada como plataforma habilitada de taxi, lo cual no implica API. [Taxia Life](https://taxialife.com/negocios/) · [MinTransporte](https://gestiondocumental.mintransporte.gov.co/nuez/2025/407/20254071089781_65495.pdf) — confianza alta/ media según afirmación.
- Jelpit se presenta actualmente como plataforma de recaudo, cartera y pagos, no como proveedor de movilidad/delivery; puede haber una confusión de nombre. [Jelpit](https://jelpit.com/) — confianza alta.

## Leads y vacíos

- Contactar a Uber Direct/Business sobre cobertura, tarifas, SLA y permisos de producción en Colombia.
- Solicitar a Rappi, inDrive, DiDi y Taxia el alcance de APIs privadas, programas de partners y autorización para middleware.
- Confirmar el nombre del proveedor que se entendía por Jelpit.
